# 🍽️ Savoria — Modern Restaurant & Dining Experience

A responsive restaurant website concept with a food menu, add-to-order interactions, and a reservation request form.

## Live website
https://pixel-perfect-showcase-4470.lovable.app

## Features
- Responsive layout for desktop and mobile
- Restaurant story and featured dishes
- Add-to-order interaction with a running total
- Reservation form with name, email, guests, date, time, and special requests
- Date picker prevents selecting a date before today
- Mobile navigation

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build tools are required for this static version.

## Important note
This is a **reconstructed starter source package**, not a direct export of the private/original Lovable project. The live Lovable site and this package are separate until you sync the original project through Lovable's GitHub integration. The reservation form currently displays a demo confirmation; it is not connected to a backend or webhook.
